config.toml

ทุกค่าในหน้านี้เขียนลงไฟล์ config เดียวของ agent — ส่วนอื่นของระบบอ่านจากไฟล์นี้เท่านั้น

Server [server]

การแก้ค่า server จะย้าย listener ให้เอง หากเปิด port ใหม่ไม่ได้จะคงค่าเดิม / server changes apply without restarting the agent.

เครื่องอื่นบนเครือข่ายเข้าถึง agent ได้ (listen = 0.0.0.0) — ต้องมี token ดูหัวข้อถัดไป / other devices can reach the agent; a token is required, see below.
bind เฉพาะ interface ได้ เช่น 192.168.1.10 — ค่าอื่นที่ไม่ใช่ loopback ถือว่าเปิดเครือข่ายเช่นกัน / a specific interface; anything beyond loopback counts as exposed too.

* อนุญาตทุก origin / * allows any origin

⚠ ตอนนี้อนุญาตทุก origin: เว็บไซต์อื่นที่คุณเปิดก็อ่านบัตรได้ / any site you visit can read the card.

Socket token [server] token

ต้องมีเมื่อเปิดให้เครือข่ายภายนอกเข้าถึง / required when the agent listens beyond localhost. ส่งผ่าน ?token= บน URL ของ socket หรือ Authorization: Bearer — โชว์ครั้งเดียวตอนสร้าง / shown once when generated.

TLS [tls]

จำเป็นเมื่อหน้าเว็บภายนอกเป็น https แล้วคุยกับ agent / needed when an https page talks to the agent. ใบรับรองต้องเชื่อถือได้โดยเครื่องที่รันเบราว์เซอร์ / the certificate must be trusted by the machine running the browser.

การบันทึกเขียน config.toml ใหม่ทั้งไฟล์: comment ที่เพิ่มเองจะหาย / saving rewrites config.toml from a template — comments added by hand are lost. การแก้ไฟล์เองมีผลหลังรีสตาร์ท / hand edits take effect after a restart.
